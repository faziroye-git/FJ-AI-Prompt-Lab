# AI Prompt Lab

AI Prompt Lab is a personal Java-based AI application for experimenting with AI prompts, APIs, and AI application development.

## Project Status

🚧 **In Development**

This project is being built as a practical learning project to develop skills in Java, backend development, REST APIs, AI API integration, and eventually full-stack development.

## Current Technology

* Java
* Spring Boot
* Maven
* REST API
* Git & GitHub

## Current Features

* Spring Boot application setup
* Basic REST controller
* `/hello` endpoint
* Git version control
* Public GitHub repository

## Planned Features

* AI API integration
* Prompt submission and processing
* AI response display
* Prompt experimentation
* Response and experiment history
* AI model comparison
* JSON request and response handling
* Frontend interface
* Database integration
* Automated testing

## Learning Goals

This project is being developed step-by-step to gain practical experience with:

* Java application development
* Backend development
* REST APIs
* HTTP requests and responses
* JSON
* API authentication
* External API integration
* AI application development
* Frontend and full-stack development
* Git and GitHub

## Project Development

The project will evolve incrementally as new features and technologies are introduced. The GitHub repository documents the development process and progress of the application.

## Recent Update

The project now includes a dedicated development branch workflow. Changes can be developed and reviewed on `subbranch` before being merged into `main`.
